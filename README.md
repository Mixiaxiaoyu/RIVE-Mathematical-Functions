colorMode 粒子颜色。0–360 表示色轮色相，361 表示白色，362 表示黑色。
shapeMode 粒子形状。0 表示方形粒子，1 表示菱形，2 表示十字，3 表示线段。
speed 动画速度。1 为正常速度，低于 1 更慢更柔，高于 1 更快。
seed 函数形态种子。改变 seed 会生成不同的形态，
particleCount 粒子数量。数值越高越细腻，但性能消耗越大。
shapeScale 整体图形大小。数值越大，主体越大；过大可能会被画布裁切。
alpha 粒子透明度。范围 0–255，数值越高越亮，过高容易糊成一片。
particleSize 单个粒子尺寸。数值越小越细腻，数值越大越厚重。
